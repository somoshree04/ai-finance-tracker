
# ⚡ Backend system 

The core application server. Built with FastAPI and SQLAlchemy, it handles user management, financial logging, and asynchronous database interactions. It dynamically resolves system paths to load the ML core and evaluate expense data in real time before storing it.

---

## 🏛️ System Workflow & API Routes

When an endpoint is called, the application translates structural JSON request bodies into data frames for predictive calculation and then writes them to disk.

```
[ Inbound POST /expenses/ ] ──► Validates via schemas.ExpenseCreate
                                          │
                                          ▼
                                Looks up CATEGORY_MAP ──► Pass to ml.predict_anomaly()
                                                                   │
                                                                   ▼
 [ Persistent SQLite Disk ] ◄── Saves models.Expense ◄── Injects True/False boolean
```

### Exposed REST Endpoints

| Method | Route | Request Body | Response Model | Description |
|---|---|---|---|---|
| POST | `/users/` | `UserCreate` | `User` | Registers a new user with email verification. |
| POST | `/users/{user_id}/expenses/` | `ExpenseCreate` | `Expense` | Ingests a new transaction, triggers real-time ML anomaly evaluation, and saves the result. |
| GET | `/users/{user_id}/expenses/` | None | `list[Expense]` | Retrieves all historical expenses for a user. Returns `[]` if no logs exist. |

## 📄 File Breakdown

### 🚀 `main.py` — Application Orchestrator & ML Gateway

Sets up Cross-Origin Resource Sharing (CORS), maps routing paths, and runs interceptor pipelines for model inference.

- **Dynamic Path Resolution** — Modifies `sys.path` at runtime to append the parent directory, ensuring `import ml_logic.model as ml` works even though the ML workspace sits outside the backend root.
- **CORS Permissions** — Opens connection channels for local development (`http://localhost:5173`) and the live production client (`https://ai-finance-tracker-opal.vercel.app`).
- **Category Matrix Binding** — Holds the static index map (`CATEGORY_MAP`) corresponding to labels generated during training (e.g., `Eating_Out: 0`, `Utilities: 10`).
- **Real-time Anomaly Hook** — Inside `create_expense_for_user`, translates text categories into numerical values, sends them to `ml.predict_anomaly()`, and assigns the resulting boolean to the database model instance (`is_anomaly=is_anomaly_detected`).

---

### 📐 `models.py` — Relational Database Schemas

Declares the physical layout of relational tables using SQLAlchemy.

- **User Table** — Stores identity baselines: `id`, `username`, `email`, `hashed_password`.
- **Expense Table** — Maintains transactional metadata including a floating-point `amount`, a boolean `is_anomaly` flag (defaulting to `False`), and a timestamp auto-generated by the database via `server_default=func.now()`.
- **Relational Mapping** — Implements a strict One-to-Many relationship via `ForeignKey("users.id")` and `relationship()`, linking individual expense rows to their owning user.

---

### 📝 `schemas.py` — Pydantic Validation & Serialization

Validates that inbound payloads contain complete, correctly-typed fields before they reach core server logic.

- **Separation of Concerns** — Differentiates incoming shapes (`ExpenseCreate` / `UserCreate`) from outgoing shapes (`Expense` / `User`), keeping server-managed fields like timestamps and IDs out of request bodies.
- **Email Guarding** — Uses `EmailStr` typing to block invalid email formats at the network gateway.
- **ORM Conversion** — Uses `from_attributes=True` in `Config` classes, allowing FastAPI to read native SQLAlchemy objects and serialize them directly into JSON.

---

### 🗄️ `database.py` — Engine & Session Providers

Configures the low-level communication link to local file storage.

- **Threading Adaptability** — Passes `connect_args={"check_same_thread": False}` to allow concurrent async requests to safely hit the SQLite file.
- **`get_db()` Dependency Injector** — A generator that creates clean transactional sessions per route request and runs `finally: db.close()` to safely recycle connections and prevent memory leaks.

## 🚀 Running Locally

From the project root, run Uvicorn to ensure `ml_logic` path mapping resolves correctly:

```bash
uvicorn backend.main:app --reload --port 8000
```

Then open [http://localhost:8000/docs](http://localhost:8000/docs) to interact with the API via the auto-generated Swagger interface.
